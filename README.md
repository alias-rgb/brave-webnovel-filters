# Brave Android Custom Filters for Web Novel Sites

Custom Brave Shields filters designed to improve the reading experience on mobile browsers for:

* `novelfire.net`
* `freewebnovel.com`

## Installation

1. Open Brave Browser on Android
2. Go to:

```text id="4gt54m"
Settings → Shields → Content Filtering
```

3. Tap:

```text id="srywy8"
Add custom filter list
```

4. Paste one of the following raw GitHub URLs into Brave:

```text
https://raw.githubusercontent.com/alias-rgb/brave-webnovel-filters/main/freewebnovel.txt
```

```text
https://raw.githubusercontent.com/alias-rgb/brave-webnovel-filters/main/novelfire.txt
```

OR

Copy the filter rules manually into:

```text id="q5jeqa"
Create custom filters
```

## Filter Lists

```text id="df67oq"
novelfire.txt
freewebnovel.txt
```
